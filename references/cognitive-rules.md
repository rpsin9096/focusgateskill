# Cognitive Ergonomics Reference

Shaped for readers with executive function constraints:

## 1. Action-First Output
- Place the executable command, file edit, or single bounded question on line 1.
- Begin immediately with the operational deliverable.

## 2. Persistent State Vector
- Place the state vector on line 2: `State: [Step X of Y] [Z/W gates met] [Est: MM min]`.
- Re-anchor reader working memory on every turn.

## 3. Numbered Sequences
- Present multi-step work as numbered sequences (`1.`, `2.`, `3.`).
- Limit each item to a single bounded action.

## 4. Working Memory Cap
- Restrict lists to at most 5 items per group.
- Retain secondary items internally until they become the active set.

## 5. Concrete Time Units
- Express estimates in explicit minutes or hours (e.g. "15 minutes", "2 hours").

## 6. Visible Milestones
- State newly functional outcomes directly.
- Point to executable verification commands to confirm working progress.

## 7. Immediate Terminal Step
- End responses with one bounded action doable in under two minutes.
